## [0.1.0] - 2026-11-15

### Добавлено

- Таблица статуса локальных Git-репозиториев на `rich`: Repository, Branch, Status, Staged, Modified, Untracked, Sync.
- Параллельный сбор статусов через семафор `asyncio` (до 8 одновременных процессов git).
- Команда по умолчанию `gward`: быстрая локальная проверка без сети.
- Подкоманда `gward fetch`: выполняет `git fetch --prune` во всех репозиториях и показывает обновлённый статус, поэтому колонка Sync отражает remote.
- Флаг `-d` / `--dirty`: показывает только репозитории, которые требуют внимания (ошибки, локальные правки, расхождение с remote).
- Опция `-C` / `--dir` для выбора папки (по умолчанию текущая).
- Флаг `--debug`: выводит время выполнения под таблицей.
- Парсер вывода `git status --porcelain=v2 --branch` как чистая функция.
- Тесты: парсер на фикстурах, интеграционные тесты на временных репозиториях с локальным bare-remote, тест ограничения параллельности, тесты вывода.
- `README.md` и `README.en.md`.

### Изменено

- Вывод CLI и комментарии в коде на английском.
- В колонке Sync при отсутствии upstream показывается `—` вместо `↑0 ↓0`, которое вводило в заблуждение.

### Исправлено

- Репозитории, у которых `.git` является файлом (worktree, submodule), определяются корректно.
- Зависшие процессы git снимаются по таймауту: 10 секунд для статуса, 60 секунд для fetch.
- Git не запрашивает учётные данные (`GIT_TERMINAL_PROMPT=0`) и не берёт необязательные блокировки индекса (`GIT_OPTIONAL_LOCKS=0`).
- Тест fetch без remote проверял неверное поведение: `git fetch` без remote возвращает код 0. Тест переписан на реальный сбой с недоступным remote.
